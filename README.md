# Data Analyst Agent

A small Python tool for answering questions about a table. The analysis is done by a handful of reusable, tested tools. A person can write the plan by hand, or a language model can propose it. Either way the plan is checked before anything runs.

## Tools

| Tool | What it does |
|---|---|
| `describe` | rows, column types, missing values, numeric summary |
| `filter_rows` | keep rows where a column matches a condition (later steps use the filtered rows) |
| `group_summary` | sum, mean, median, min, max or count of a column per group |
| `top_n` | the n largest or smallest rows by a column |
| `value_counts` | how often each value occurs |

A plan is a list of steps, for example "keep laptops, then show the three orders with the most units":

    [{"tool": "filter_rows", "args": {"column": "product", "op": "==", "value": "laptop"}},
     {"tool": "top_n", "args": {"column": "units", "n": 3}}]

## Error handling

- Tools never raise on bad input. They return a clear message, for example `Unknown column 'colour'. Available columns: date, region, ...`.
- A plan is validated before it runs: unknown tools, unknown arguments and unknown columns are reported up front.
- Running stops at the first failing step and reports which step failed.
- `load_csv` handles a missing file, an empty file, a header-only file and unreadable content.

## Optional: a model writes the plan

`plan_with_llm` sends a model the question, the column names with their types and the tool list. It sends **no rows**. If the plan is invalid, the errors are sent back once and the model gets one chance to correct it. A reply that still cannot be used becomes a clear error message and nothing is executed.

## Run

    py -m pip install pandas
    py run_demo.py

The demo uses a generated sales table and three questions, one of which fails on purpose to show the error message. No API key is needed. To let a model plan instead:

    set GEMINI_API_KEY=your_key
    set LLM_MODEL=gemini-3.5-flash-lite
    py run_demo.py --llm

If no key is set, `llm_client.py` asks for one when it starts. To describe your own file: `py run_demo.py --csv my.csv`.

## Test

    py -m unittest test_analyst.py

20 tests cover each tool, error cases, plan validation, the repair loop (with a fake model) and a check that the model prompt contains no row data.

## Limits

- The demo data is generated by me. It shows how the tools and error handling work, not performance on real datasets.
- The model-planning path is tested with a fake model. It has not been evaluated with a real model yet.
- Only five tools, no joins, no charts and no multi-column grouping.
